# Student Database System (Linked List) - C++

Menu-driven student database program implemented using a singly linked list.

## Features
- Insert record at any position
- Delete record at any position
- Search by last name
- Print range of records
- Compute course class average

## How to Run

Compile (Mac):
clang++ -std=c++11 main.cpp -o studentdb

Compile (Linux):
g++ -std=c++11 main.cpp -o studentdb

Run:
./studentdb
